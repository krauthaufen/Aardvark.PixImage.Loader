## XZ Utils / LZMA SDK (BCJ filter definitions)

`src/Aardvark.PixImage.PixCodec/Core/Compression/BcjFilters.cs`

- The IA-64 table that tells which slots of a bundle template can hold a branch (`Ia64BranchSlots`) has the same
  content as the table in XZ Utils (`src/liblzma/simple/ia64.c`) and the LZMA SDK (`Bra.c`/`BraIA64.c`).
- The .xz format documents the BCJ filters only by reference to their implementation, so the exact conversions
  (which instructions, which bits, the x86 look-back rule, the ARM64 ADRP range rule and the layout of the RISC-V
  filter) follow the behaviour of XZ Utils. The RISC-V layout was taken from the description in
  `src/liblzma/simple/riscv.c`. The code here is written independently and verified against files made by `xz`.

## BPTC (BC6H / BC7) partition and anchor tables

`src/Aardvark.PixImage.PixCodec/Dds/Bptc.cs` contains the BPTC partition tables (64 two-subset and 64 three-subset partitions of a 4x4
block) and the anchor index tables, converted by script from the text of the Khronos Data Format Specification
(https://github.com/KhronosGroup/DataFormat, `bptc.txt`), and the BC6H endpoint bit layouts, transcribed from
Microsoft's "BC6H Format" documentation (https://learn.microsoft.com/windows/win32/direct3d11/bc6h-format, CC BY 4.0,
https://github.com/MicrosoftDocs/win32). Only these tables were taken; the decoders are written from the prose of the
two documents. The tables are the format's definition: every BC6H / BC7 decoder carries the same values, e.g.
Microsoft's DirectXTex (MIT licence, https://github.com/microsoft/DirectXTex), which was not used here.

Khronos Data Format Specification: Copyright (c) 2014-2025 The Khronos Group Inc. Used for implementing the
functionality it describes, as its copyright notice (https://www.khronos.org/registry/speccopyright.html) permits.

Microsoft documentation: Copyright (c) Microsoft Corporation, licensed under the Creative Commons Attribution 4.0
International licence (https://creativecommons.org/licenses/by/4.0/).

## Khronos Data Format Specification - ETC and ASTC tables

`src/Aardvark.PixImage.PixCodec/Ktx/EtcBlocks.cs` and `src/Aardvark.PixImage.PixCodec/Ktx/AstcBlocks.cs` contain tables printed in the Khronos Data Format
Specification 1.3 (https://registry.khronos.org/DataFormat/specs/1.3/dataformat.1.3.html): the ETC1 / ETC2 intensity
modifier and distance tables, the EAC modifier tables, and the ASTC weight / colour quantisation and unquantisation
tables. Only the table values were taken; the decoders are written from the specification's text.

## Basis Universal specifications - ETC1S and UASTC tables

`src/Aardvark.PixImage.PixCodec/Ktx/BasisEtc1s.cs` and `src/Aardvark.PixImage.PixCodec/Ktx/BasisUastc.cs` contain tables printed in Binomial's
".basis File Format and ETC1S Texture Video Specification" and "UASTC LDR 4x4 Texture Specification"
(https://github.com/BinomialLLC/basis_universal/wiki) and in Appendix C / D of the KTX 2.0 specification. Only the table
values were taken; no code of basis_universal was used.

## ISO/IEC 18181-1 (JPEG XL) - default parameter tables

`src/Aardvark.PixImage.PixCodec/Jxl` contains the default parameters that ISO/IEC 18181-1:2024 "JPEG XL image coding
system - Part 1: Core coding system" defines as part of the bitstream: the default dequantization table parameters of
the 17 quantization tables (`JxlQuantTables.cs`), the AFV basis (`JxlTransforms.cs`), the default 2x / 4x / 8x
upsampling weights (`JxlUpsampling.cs`), the delta palette (`JxlModularDecode.cs`), the 120 special LZ77 distances
(`JxlEntropy.cs`), the ICC tag / type string tables of the ICC compression (`JxlIcc.cs`), the default weighted predictor,
opsin inverse, noise and spline constants, and the AC strategy shapes and orders (`JxlAcStrategy.cs`). They are data
that every conforming decoder must use; the code is written independently. The 8x upsampling weights were recovered
from the output of libjxl (run as an oracle) by least squares and agree with the standard's values to float precision.

## RFC 7932 (Brotli) - static dictionary and transforms

`src/Aardvark.PixImage.PixCodec/Core/Compression/BrotliDictionary.zlib` holds the 122,784 byte static dictionary of
RFC 7932 "Brotli Compressed Data Format" (Appendix A), extracted from the RFC text by script and checked against the
CRC-32 the RFC gives; `BrotliDecoder.cs` contains the 121 word transforms of Appendix B and the context lookup tables of
section 7.1. The decoder is written from the RFC's prose.
